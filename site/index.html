RDAP SERVER DIRECTORY

IANA's bootstrap + hand-maintained ccTLD servers · one stable URL

WELCOME to rdapserver.org, the friendly home of the RDAP server lookup. Now with the ccTLD coverage IANA leaves out. Point your RDAP client at a single URL. It's SMALL DATA and it's ALL IN ONE PLACE.

> WHAT IS RDAP?

RDAP (Registration Data Access Protocol, RFC 7480–7484) is the modern replacement for WHOIS. To look a domain up you first need to know which server answers for its TLD.

> WHAT IS THIS?

IANA publishes a canonical bootstrap file, but it lists only some ccTLDs — each ccTLD is self-governed, so most are missing. This project adds a small, hand-maintained overlay for those gaps, then republishes IANA's file and the overlay together as one merged RFC 7484 bootstrap.

> THE SINGLE URL

Point any RDAP client at one stable URL — IANA's canonical file with the missing ccTLDs folded in, always IANA first: 

$ https://data.rdapserver.org/dns.json

> THE RECIPE

  1. The IANA bootstrap stays canonical for everything it covers.
  2. The overlay is a delta: only the TLDs IANA omits.
  3. IANA always wins — when IANA adds a ccTLD itself, the overlay quietly defers.
  4. IDNs are punycoded to their A-label (xn--) before lookup.

> USE IT

Build it with cargo install --git https://github.com/devshubho/rdap-server. The ccTLD overlay ships as data/manual/cctld-rdap-servers.json, so run from a checkout or pass --overlay to point at it. 

$ rdap-lookup example.com
example.com	.com	https://rdap.verisign.com/com/v1/

$ rdap-lookup --server-only nic.ch
nic.ch	.ch	https://rdap.nic.ch/

> ccTLD RDAP SERVERS

ICANN governs the gTLDs and requires each one to run RDAP. The ~250 ccTLDs each govern themselves, so every one decides on its own whether to run RDAP, WHOIS, or neither. IANA's bootstrap lists only some of them — the rest are the gaps this project fills.

Every entry records where we found the URL (source) and when it was last confirmed (date_updated) — usually an official page, sometimes a best-effort guess. Since ccTLD URLs move, a scheduled check probes the servers we list so stale ones surface early.

> NO RDAP?

Not every ccTLD runs an RDAP server. When none is known, fall back to WHOIS — the full TLD dataset (from the iana-data project) carries whois_server alongside rdap_server.
